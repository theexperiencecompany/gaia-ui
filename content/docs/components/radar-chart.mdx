## Usage in Gaia

Used to compare entities across multiple dimensions at once — skill profiles, model evaluations, or feature scorecards — where shape conveys strengths and weaknesses.

## Features

- **Multi-Dimensional** - Plot any number of axes around the polar grid
- **Multi-Series Support** - Overlay multiple shapes for side-by-side comparison
- **Custom Tick Labels** - Each axis displays both value and dimension name
- **Auto Legend** - Appears automatically with two or more series
- **Translucent Fills** - Areas overlap cleanly with `fillOpacity={0.2}`
- **Theme-Aware** - Built on the shadcn chart primitive

## Usage

```tsx
import { RadarChart } from "@/components/ui/radar-chart";

const data = [
  { skill: "Speed", you: 82, team: 70 },
  { skill: "Accuracy", you: 91, team: 75 },
  { skill: "Reliability", you: 76, team: 80 },
];

export default function Example() {
  return (
    <RadarChart
      data={data}
      angleKey="skill"
      valueKeys={["you", "team"]}
      title="Performance"
    />
  );
}
```

## Props

### RadarChart

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| data | Array&lt;Record&lt;string, string \| number&gt;&gt; | - | Chart data rows |
| angleKey | string | - | Key on each row used for the axis label |
| valueKeys | string \| string[] | - | One or more numeric keys to plot |
| title | string | - | Card title |
| description | string | - | Card description |
| footer | string | - | Optional footer text |
| colors | string[] | CHART_COLORS | Custom palette for series |
